# FEASTY MERCHANT Roadmap

The roadmap is organized into product versions so each stage can be delivered
with a stable foundation before the next set of workflows is introduced.

```text
Version 1 -> Version 2 -> Version 3 -> Version 4 -> Version 5
   UI          Onboarding      AI          Reputation      Ecosystem
 Foundation   + Verification  Workflows   + League       Integration
```

## Version 1 — UI Foundation

- Establish the FEASTY MERCHANT visual language and reusable design system.
- Build responsive landing, login, signup, business type, and dashboard shell
  experiences.
- Establish navigation, layout primitives, and project documentation.
- Prepare the Supabase client foundation without connecting product workflows.

## Version 2 — Merchant Registration + Verification

- Connect merchant registration to approved authentication flows.
- Create organization, business, branch, and profile setup workflows.
- Add verification request submission and administrative review.
- Publish only approved business information to FEASTYMAP.
- Add merchant profile completion and onboarding states.

## Version 3 — AI Voice + Menu Extraction

- Introduce AI-assisted menu extraction from supported inputs.
- Explore voice-assisted merchant updates.
- Add structured review and approval before AI-generated changes are published.
- Support Tamil and English voice experiences as quality and safety allow.

## Version 4 — Reviews + Reputation + Business League

- Add moderated reviews and merchant reputation views.
- Introduce reputation signals and business performance summaries.
- Explore a Business League experience with transparent rules.
- Add merchant-facing tools to understand and respond to reputation trends.

## Version 5 — FEASTYMAP Integration + Super Admin + Analytics

- Deepen FEASTYMAP discovery and merchant publishing integration.
- Build super-admin workflows for platform operations and moderation.
- Add merchant analytics, platform analytics, and reporting foundations.
- Expand organization, branch, and content governance at ecosystem scale.

## Future ideas

The following ideas are candidates for discovery and prioritization after the
core platform workflows are stable:

- Blue Tick verification signal.
- Instagram Signal for eligible business activity.
- QR Offers for offline-to-online campaigns.
- Multiple Branches management.
- Tamil + English Voice.
- AI Content Validation.
- Competition System.
- Merchant Analytics.

These ideas are intentionally not implementation commitments. Each requires
separate product, trust, privacy, and technical design review before entering a
release scope.
